SHURU KARNE SE PEHLE

N8N hai kya, aur local kyun?

N8N ek automation tool hai. Aap boxes (jinhe "nodes" kehte hain) ko line se jodte ho, aur kaam apne aap hone lagta hai. Jaise: form bhara gaya, toh Google Sheet mein entry, aur WhatsApp par message. Bina coding ke.

Local install matlab: N8N aapke apne laptop par chalega. Koi monthly fees nahi, aapka data aapke paas. Seekhne aur practice ke liye ye sabse badhiya tareeka hai.

Aapko kya chahiye

LaptopWindows 10 (22H2) ya Windows 11, 64-bit. Ya koi Mac.
RAM8 GB ya zyada. 4 GB par bahut slow chalega.
InternetLagbhag 2 GB download hoga (Docker + N8N).
SamayPehli baar 30 se 45 minute. Chai saath rakhiye.

Docker se N8N: Step by step

1

Laptop check karo

2 min

(a) Windows version: Windows key dabao, type karo winver, Enter. Window mein "Version 22H2" (Windows 10) ya "Windows 11" dikhna chahiye.

(b) RAM: Settings > System > About > "Installed RAM". 8 GB ya zyada ho toh perfect.

(c) Virtualization ON hai ya nahi: Ctrl + Shift + Esc se Task Manager kholo > Performance tab > CPU. Neeche right side mein likha hoga:

Task Manager > Performance > CPU
Base speed:      2.40 GHz
Cores:           8
Virtualization:  Enabled   <-- ye "Enabled" hona chahiye
"Disabled" likha hai?

Laptop restart karke BIOS mein jaana padega (zyaatar F2, F10 ya Del key, company ke hisaab se). Wahan "Intel VT-x" ya "AMD-V / SVM" ko Enabled karo. Ye setting har laptop mein alag jagah hoti hai, apne laptop model ka naam + "enable virtualization" Google kar lo.

2

WSL install karo

5 to 10 min

WSL Windows ke andar ek chhota Linux hai. Docker ko chalne ke liye iski zaroorat hoti hai.

PowerShell ko "Run as administrator" se kholo (Page 3 dekho) aur ye command chalao:

Administrator: Windows PowerShell
PS C:\Windows\system32> wsl --install
Installing: Virtual Machine Platform ...
Installing: Windows Subsystem for Linux ...
Installing: Ubuntu ...
The requested operation is successful. Changes will not be effective until the system is rebooted.
  • Install ke baad laptop restart karo.
  • Restart ke baad ek Ubuntu window khul sakti hai jo username aur password maangegi. Koi bhi simple naam aur password daal do (password type karte waqt screen par kuch nahi dikhega, ye normal hai).
WSL pehle se hai?

Toh bas update kar lo: wsl --update

3

Docker Desktop install karo

10 to 15 min

Docker Desktop wo app hai jo hamara "tiffin box" (container) chalata hai. Personal use aur chhote business ke liye free hai.

  1. Browser mein kholo: docker.com/products/docker-desktop
  2. Download for Windows - AMD64 par click karo. (Aapka laptop Intel ya AMD ka hai toh yahi wala. Bahut kam laptops "ARM" hote hain.)
  3. Download hui file Docker Desktop Installer.exe par double-click karo.
  4. Installer mein "Use WSL 2 instead of Hyper-V" wala box ticked rehne do. OK dabao.
  5. Install poora hone par Close and restart (ya laptop restart) karo.
  6. Restart ke baad Docker Desktop kholo. Terms par Accept karo.
  7. Sign in / Sign up maange toh Skip kar sakte ho. Account zaroori nahi hai.
  8. Neeche left corner mein "Engine running" (hara/green) dikhe, matlab Docker taiyaar hai.

RAASTA A · KUCH HAFTON BAAD

N8N ko update kaise karein

N8N har kuch hafton mein naye features laata hai. Update karne se aapke workflows delete nahi hote, kyunki wo almirah (volume) mein safe hain. Ye 4 commands ek-ek karke chalao:

Windows PowerShell
# 1. Naya version download karo
PS C:\Users\Aap> docker pull docker.n8n.io/n8nio/n8n

# 2. Purana N8N band karo
PS C:\Users\Aap> docker stop n8n

# 3. Purana tiffin hatao (almirah safe rehti hai)
PS C:\Users\Aap> docker rm n8n

# 4. Step 6 wali command dobara chalao
PS C:\Users\Aap> docker run -d --name n8n --restart unless-stopped -p 5678:5678 -e GENERIC_TIMEZONE="Asia/Kolkata" -e TZ="Asia/Kolkata" -e N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=true -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
Kabhi mat karna

docker volume rm n8n_data ya Docker Desktop > Volumes se "n8n_data" delete. Isse saare workflows hamesha ke liye chale jaate hain.

Backup ki aadat daalo

Har important workflow ko N8N ke andar se Download (workflow ke upar right side ka menu > Download) karke ek folder mein rakh lo. Ye ek .json file hoti hai, kabhi bhi wapas Import kar sakte ho.

BONUS · 5 MINUTE

Aapka pehla workflow

Install ho gaya? Chaliye ek chhota sa workflow bana ke dekhte hain, taaki haath khul jaaye.

  1. N8N mein Create Workflow (ya "Start from scratch") par click karo.
  2. + button dabao, search karo "Manual" aur Trigger manually chuno. Ye workflow ka "start button" hai.
  3. Uske aage wale + par click karo, search karo "Edit Fields" (Set). Add Field mein Name: message, Value: Namaste N8N!
  4. Upar Execute workflow (Test workflow) dabao.
  5. Edit Fields node par hara tick aayega aur output mein "Namaste N8N!" dikhega.
Workflow ka naksha
[ Trigger manually ]  ---->  [ Edit Fields: message = "Namaste N8N!" ]
          start button                 output: { "message": "Namaste N8N!" }

Bas! Yahi N8N ka core hai: trigger (kab shuru ho) + nodes (kya karna hai). Ab Manual ki jagah Schedule, Webhook ya Google Sheets trigger lagao, aur asli automation shuru.
