------------------------------------------------------------
RAASTA A: DOCKER (Windows aur Mac)
------------------------------------------------------------

Step 2 (sirf Windows, PowerShell "Run as administrator"):
wsl --install

WSL pehle se hai toh update:
wsl --update

Step 4: Docker check:
docker --version
docker run hello-world

Step 5: N8N ki almirah (volume), sirf ek baar:
docker volume create n8n_data

Step 6: N8N chalu karo, sirf pehli baar:
docker run -d --name n8n --restart unless-stopped -p 5678:5678 -e GENERIC_TIMEZONE="Asia/Kolkata" -e TZ="Asia/Kolkata" -e N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=true -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n

N8N zinda hai ya nahi (Windows):
curl.exe http://localhost:5678/healthz

N8N zinda hai ya nahi (Mac):
curl http://localhost:5678/healthz

Browser mein kholo:
http://localhost:5678

Roz ka use:
docker start n8n
docker stop n8n
docker ps
docker logs n8n

Update (ek-ek karke):
docker pull docker.n8n.io/n8nio/n8n
docker stop n8n
docker rm n8n
docker run -d --name n8n --restart unless-stopped -p 5678:5678 -e GENERIC_TIMEZONE="Asia/Kolkata" -e TZ="Asia/Kolkata" -e N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=true -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n

Owner password bhool gaye:
docker exec -u node -it n8n n8n user-management:reset
docker restart n8n
